# 🤖 بوت الذكاء الاصطناعي لتليجرام

بوت تليجرام كامل يتصل بأي واجهة API متوافقة مع OpenAI (OpenAI، OpenRouter، Groq، Together، Gemini، DeepSeek، Mistral، Pollinations، LM Studio، Ollama... إلخ) — مع إمكانية حفظ عدة مزوّدات والتنقل بينها.

## ✨ المميزات

- ⚙️ **إضافة رابط API والمفتاح من داخل البوت** — لا حاجة لتعديل الكود
- 🌐 **دعم مزوّدين متعددين**: احفظ عدة مزوّدات (OpenRouter، Groq، Together، Gemini، DeepSeek، Mistral، Pollinations...) وتنقّل بينها بضغطة واحدة — لا حصر في شركة واحدة
- 🔌 **اختبار الاتصال** قبل الاعتماد على المزوّد
- 🤖 **جلب النماذج المرتبطة بمفتاحك** واختيارها (محادثة / صور / فيديو)
- 💬 **محادثة ذكية** مع النموذج المختار
- 🧠 **ذاكرة محادثة**: يتذكّر السياق ويلخّص الرسائل القديمة تلقائيًا (قابلة للضبط)
- 🖼️ **إنشاء الصور** من وصف نصي
- 🎬 **إنشاء الفيديوهات** من وصف نصي (للواجهات التي تدعم ذلك)
- 📕 **إنشاء ملفات PDF** من نص (يدعم العربية + عناوين وقوائم)
- 📄 **إنشاء ملفات** برمجية ونصية (Python, HTML, JSON, Markdown...) — تلقائيًا من كتل الكود في الردود أيضًا
- 📥 **قراءة الملفات المرسلة**: PDF, DOCX, XLSX, صور (رؤية), ملفات نصية/برمجية — ويجيب عن أسئلتك حولها
- 📁 **إدارة محادثات متعددة** (جديدة / تبديل / حذف)
- 📝 **تعليمات مخصصة** (System Prompt) ورسالة ترحيب قابلة للتعديل

## 🚀 التشغيل

### 1) أنشئ البوت على تليجرام
افتح [@BotFather](https://t.me/BotFather) → `/newbot` → انسخ التوكن.

### 2) شغّله محليًا
```bash
pip install -r requirements.txt
cp .env.example .env   # وضع BOT_TOKEN
python bot.py
```

### 3) شغّله بـ Docker
```bash
docker build -t ai-bot .
docker run -d --env-file .env -v ai-bot-data:/app/data ai-bot
```

### 4) على استضافة (Render / Railway / VPS...)
ارفع الكود، ضع `BOT_TOKEN` في متغيرات البيئة، وشغّل `python bot.py`.
الوضع الافتراضي Polling ويعمل على أي استضافة بدون دومين.
لاستخدام Webhook: فعّل `USE_WEBHOOK=true` وحدّد `WEBHOOK_URL` (دومين HTTPS).

## ⚙️ الإعداد من داخل البوت
بعد تشغيل البوت:
1. افتح البوت وأرسل `/start`
2. اضغط **⚙️ الإعدادات** → **🌐 المزوّدون** → اختر مزوّدًا من القائمة (أو «مخصص») وأضف مفتاحه
   - يمكنك حفظ عدة مزوّدات والتبديل بينها في أي وقت
   - Pollinations مجاني تمامًا ولا يحتاج مفتاحًا
3. اضغط **🤖 النماذج** → اختر نموذج المحادثة (ويمكنك تعيين نماذج للصور والفيديو)
4. ابدأ المحادثة! 🎉

## 📂 بنية المشروع
| الملف | الوظيفة |
|---|---|
| `bot.py` | نقطة التشغيل |
| `handlers.py` | معالجات الأوامر والأزرار والمحادثة |
| `ai_client.py` | الاتصال بواجهة الذكاء الاصطناعي |
| `memory.py` | ذاكرة المحادثة والتلخيص |
| `files.py` | حفظ الملفات واستخراج النص منها |
| `pdfgen.py` | توليد PDF عربي |
| `db.py` | قاعدة البيانات (SQLite) |
| `keyboards.py` | لوحات الأزرار |
| `config.py` | الإعدادات ومتغيرات البيئة |

## 🔐 ملاحظات أمنية
- مفتاح API يُحفظ في قاعدة البيانات المحلية (`data/bot.db`) ولا يُعرض كاملًا في أي رسالة.
- لا ترفع ملف `.env` أو مجلد `data/` إلى Git (مُستثناة في `.gitignore`).
